# VQ-VAE source references

The original bundled README describes a PyTorch implementation of Vector
Quantized Variational Autoencoders and references:

- [VQ-VAE paper](https://arxiv.org/abs/1711.00937)
- [Original TensorFlow implementation in Sonnet](https://github.com/deepmind/sonnet/blob/master/sonnet/python/modules/nets/vqvae.py)
- [Original example notebook](https://github.com/deepmind/sonnet/blob/master/sonnet/examples/vqvae_example.ipynb)

The complete historical README and CIFAR demonstration remain in the local
archive. For ProTalk training use the repository's current README and TRAINING.md.
Existing source notices are retained; these references do not grant asset or code
redistribution rights.
